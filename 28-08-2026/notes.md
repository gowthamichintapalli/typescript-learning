### 3. Basic Data Types
array  - stores multiple values of same type
tuple   -  A tuple is an array where the number and types of elements are fixed   E.G:- let person: [string, number] = ["John", 25]; First value must be a string and Second value must be a number
object  -  Objects store data in key-value pairs.
any     -  anycan use it when you don't know what type of data is going to be in a variable.
unknown -  unknownit forces us to write "bug-free" code.unknown This is the best and safest option to avoid unexpected crashes when you don't know where the data is coming from
